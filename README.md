# Fremantle Rebels Softball Club Website & Social Generator

Official website and automated social media post generator for Fremantle Rebels Softball Club (Shirley Strickland Reserve in  Ardross WA).

## Features

- **Club Website**: Responsive, dark-themed pages for Home, About, Teams, Gallery, and Join & Contact.
- **Social Media Post Generator**: 4-step wizard creating pixel-perfect 1080×1080 and 1080×1350 matchday graphics:
  1. **Fixture / Result / Announcements / Dinner Orders**
  2. **Design**: 4 templates (Classic, Scoreboard, Poster, Minimal) across Rebels Green, Gold, and Cream palettes.
  3. **Media**: Fastpitch action presets, custom drag-and-drop photo upload, zoom, pan, and darkness overlay controls..

  4. **Caption & Export**: Automated smart copy for Instagram/Facebook/TeamApp etc, one-click clipboard copy, and high-res PNG download.

- **Zero Build Dependencies**: Pure HTML5, Bootstrap 5.3, and vanilla CSS/JS. Works offline and out of the box.

## Getting Started

Open `index.html` directly in your browser or run a simple local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/`.
